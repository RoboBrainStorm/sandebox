# sandebox Admin Panel

Observability web interface for monitoring and managing `sandebox` clusters.

## Features

- **Live Cluster Metrics**: Monitor active sandboxes, uptime, and configured gVisor runtime class.
- **Active Sandboxes**: Inspect running pods, workspace attributions, and kill misbehaving instances.
- **Deployments & Builds**: View Knative services and BuildKit image pushes.
- **Key Management**: Mint and track client API keys.
